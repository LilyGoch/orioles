# orioles

This is a repository for code used for an oriole mitonuclear genomics project.

**GWASinGEMMA.md:** Annotated command line script for GWAS in GEMMA, starting with the .vcf file published in Walsh et al. (2023). This script is modified from Dr. Jen Walsh. 
**NAMETBD.Rmd:** R Markdown file containing an annotated R script for processing GWAS result data. Includes code to generate Manhattan plots and pull genes in 40kb windows of the GWAS peaks.
